# Credit Scoring Model

## Project Overview
This project predicts whether a customer's credit risk is Good or Bad using Machine Learning. It helps financial institutions evaluate loan applicants based on their financial and personal information.

## Dataset
- German Credit Dataset
- Features include:
  - Age
  - Sex
  - Job
  - Housing
  - Saving Accounts
  - Checking Account
  - Credit Amount
  - Duration
  - Purpose
- Target:
  - Risk

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Machine Learning Algorithm
- Random Forest Classifier

## Steps Performed
- Loaded the dataset
- Handled missing values
- Encoded categorical variables
- Split the dataset into training and testing sets
- Trained the Random Forest model
- Evaluated model performance
- Generated Confusion Matrix
- Generated Feature Importance Graph
- Saved the trained model
